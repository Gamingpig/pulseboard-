Google Health API verbinden

Einmalig einrichten – läuft danach 100 % lokal im Browser
  1. Öffne die Google Cloud Console und erstelle ein Projekt (z. B. PulseBoard).
  2. Aktiviere die Google Health API (health.googleapis.com).
  3. Gehe zu OAuth-Zustimmungsbildschirm → Extern, Status Testen, und füge deine eigene Gmail-Adresse unter Testnutzer hinzu.
  4. Erstelle unter Anmeldedaten eine OAuth 2.0-Client-ID (Typ: Webanwendung) und trage diese URL unter Autorisierte Weiterleitungs-URIs ein:
